وصف المشروع وأهدافه:
مشروع "نظام إدارة مكتبة رقمية مبسط" يهدف إلى تصميم وتطوير نظام يمكنه إدارة المكتبة الرقمية بشكل فعال. من خلال هذا النظام:

يمكن إدارة الكتب، المستعيرين، وعمليات الإعارة والاسترجاع.

يتم التركيز على تطبيق مفاهيم البرمجة الكائنية (OOP) من خلال:

استخدام الأصناف لتمثيل الكائنات (مثل كتاب، مستعير، عملية إعارة).

تطبيق مبادئ التغليف (Encapsulation)، الوراثة (Inheritance)، وتعدد الأشكال (Polymorphism).
